- **طلب المستخدم:** بناء التطبيق كاملًا، وإضافة ملف محلي يوضح الخطوات المنفذة والحالية والمتبقية لاستكمال المشروع بأي نموذج ذكاء اصطناعي لاحقًا.
- **ملف المتطلبات:** `📋 متطلبات نظام إدارة الأوردرات.md` — يحدد الأدوار والوظائف ونماذج البيانات والواجهة والجودة.
- **ملف قواعد التنفيذ:** `AI Implementation Speckit.md` — يحدد ترتيب الوحدات، قواعد الكتابة، ترتيب تحميل JavaScript، وخطوات الاختبار. تم التعامل معه كمرجع تنفيذ وليس كطلب منفصل من المستخدم.

## الخطوة الحالية غير المكتملة

**التحقق التشغيلي المتكامل عبر متصفح فعلي**: يجب فتح `index.html` محليًا، وتجربة الحسابات والأدوار، وفحص Console على Chrome/Firefox/Safari، واختبار المقاسات 320px و768px و1024px+. هذه الخطوة لم تُغلق بعد في هذه الجولة.

- [x] فحص صياغة جميع ملفات JavaScript بواسطة `node --check`.
- [x] اختبار طبقة التخزين في بيئة معزولة: seed صحيح، المصادقة صحيحة، والإحصائيات قابلة للحساب.

## الخطوات المتبقية

1. تشغيل التطبيق عبر خادم محلي أو فتح `index.html` في المتصفح.
2. اختبار تسجيل الدخول بالحسابات:
   - المسؤول: `admin / admin123`
   - أحمد: `ahmed / ahmed123`
   - سارة: `sara / sara123`
   - عمر: `omar / omar123`
3. اختبار صلاحيات المسوّق: عدم ظهور التكلفة/الربح، وعدم تعديل أو حذف أوردرات مسوق آخر.
4. اختبار CRUD للمسوقين والمنتجات والأوردرات.
5. اختبار CSV والطباعة والتقارير والرسوم.
6. إصلاح أي أخطاء تظهر في Console أو اختلافات بصرية.
7. اختبار المتصفحات والأجهزة الحقيقية، ثم نقل الحالة العامة إلى **مكتملة**.
8. اختياري للإنتاج: استبدال localStorage بواجهة خلفية حقيقية وتشفير كلمات المرور بخوارزمية آمنة؛ Base64 مناسب فقط للتطبيق المحلي التجريبي حسب الوثيقة.

## طريقة الاستئناف لنموذج ذكاء اصطناعي آخر

1. اقرأ هذا الملف كاملًا.
2. اقرأ ملف المتطلبات وملف `AI Implementation Speckit.md`.
3. ابدأ من بند **الخطوة الحالية غير المكتملة**.
4. لا تعِد إنشاء البيانات إذا كان مفتاح `oms_initialized` موجودًا.
5. بعد كل اختبار، حدّث هذا الملف بعلامة [x] أو [ ] وسجّل أي مشكلة وملفها.
6. لا تغيّر متطلبات الصلاحيات: المسؤول يرى الماليات، والمسوق لا يراها.

## التشغيل

افتح `index.html` مباشرة أو استخدم خادمًا محليًا داخل مجلد المشروع. يعتمد الخط Chart.js وCairo على CDN عند توفر الإنترنت؛ بقية التطبيق تعمل محليًا.
